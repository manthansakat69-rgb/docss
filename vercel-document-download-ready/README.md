# Sample Documents — Vercel Ready

This is a static HTML site. No Node.js or build step is required.

## Deploy on Vercel

### Option 1 — Vercel website
1. Open Vercel and sign in.
2. Create a new project.
3. Upload this project folder/ZIP or import the GitHub repository.
4. Framework Preset: **Other** (or leave auto-detected).
5. Build Command: leave empty.
6. Output Directory: leave empty.
7. Deploy.

### Option 2 — GitHub
Upload all files while keeping this structure:

```text
index.html
vercel.json
public/
  images/
    sample-1.jpg
    sample-2.jpg
    sample-3.jpg
    sample-4.jpg
    sample-5.jpg
```

Then import the GitHub repository into Vercel.

## Important
The supplied images contain identity-document information. Do not deploy real Aadhaar/PAN or other personal documents publicly. Use fictional/redacted demo images for a public project.
